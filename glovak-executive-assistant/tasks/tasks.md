## How to use this file

- Add a new row for each new task. Use the next available `T###` ID.
- Status is one of: `Open`, `In Progress`, `Blocked`, `Done`.
- When a task is completed, move its row to `tasks/completed.md` and delete
  it from this file.
- Tasks with no `Due` date are not time-bound — that's fine for P3/P4 work.
