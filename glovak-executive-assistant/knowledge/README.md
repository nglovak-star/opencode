# Knowledge Base

Structured reference material, organized by category:

- `business/` — general business notes
- `ai/` — AI tools, techniques, and industry notes
- `hospitality/` — hospitality industry and technology notes (Glovak
  Intelligence's focus area)
- `marketing/` — marketing notes
- `sales/` — sales notes
- `strategy/` — strategic planning notes
- `personal-development/` — personal growth and skill-building notes
- `reference/` — anything that doesn't fit the above (glossaries,
  cheat-sheets, misc. reference)

Each category is a folder of markdown files. Before saving something new,
check whether a related file already exists — update it instead of creating
a near-duplicate.
