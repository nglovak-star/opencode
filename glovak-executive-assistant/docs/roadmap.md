# Roadmap

This defines what's in scope right now vs. later. When in doubt about
whether something is "Version 2," check here.

## Phase 1 — Foundation (this build)
Directory structure, configuration, core instructions, task system, project
system, idea inbox, memory structure, basic commands, documentation.

## Phase 2 — Executive Workflows (next, pending approval)
Daily briefing, weekly review, focus workflow, decision support, project
status, accountability workflow. (Scaffolded already in Phase 1 — commands
exist — but should be exercised and refined with real use before calling
Phase 2 "done.")

## Phase 3 — Knowledge + Research
Deeper knowledge management, research workflow refinement, source
tracking, information retrieval across the knowledge base.

## Phase 4 — External Integrations
Calendar, email, cloud files, automation platforms, CRM. Only after the
internal system (Phases 1-3) is proven through real use.

## Phase 5 — Advanced AI Capabilities
Only after the fundamentals are proven. Not defined yet.

## Explicitly out of scope for Version 1
- Any client-facing hospitality AI product or platform.
- Multi-tool automation beyond what a human explicitly requests.
- Auto-sending any external communication.
- Anything not needed to make the personal Executive Assistant work.

If a request falls outside the current phase, it gets captured in
`ideas/idea-inbox.md` and deferred — see the anti-scope-creep rule in
`core/instructions.md`.
