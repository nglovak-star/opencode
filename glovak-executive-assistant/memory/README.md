# Memory System

Seven files, each with one job. Keep entries short and durable — this is not
a diary, it's the assistant's long-term memory.

| File | Contains |
|---|---|
| `user-profile.md` | Stable facts about Glovak (role, working style, standing constraints) |
| `active-goals.md` | Current top-level objectives |
| `project-memory.md` | Cross-project context worth remembering (mirrors key facts from `projects/projects.md`) |
| `preferences.md` | How Glovak wants the assistant to operate |
| `decisions.md` | Index of important decisions made (full analysis lives in `decisions/decisions-log.md`) |
| `lessons.md` | Lessons learned from work, mistakes, and reviews |
| `temporary-context.md` | Short-lived context — safe to prune during a weekly review |

Update these when something durable changes. Don't log routine task activity
here — that belongs in `tasks/` and `daily/`.
