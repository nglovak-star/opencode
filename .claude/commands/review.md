---
description: Run the weekly executive review
---

Read `glovak-executive-assistant/core/instructions.md` first.

1. Read `glovak-executive-assistant/tasks/tasks.md`,
   `glovak-executive-assistant/tasks/completed.md`,
   `glovak-executive-assistant/projects/projects.md`,
   `glovak-executive-assistant/ideas/idea-inbox.md`, and the past week's
   files in `glovak-executive-assistant/daily/`.
2. Determine this week's ending date (ask if unclear).
3. Create `glovak-executive-assistant/weekly/<YYYY-MM-DD>.md` using
   `glovak-executive-assistant/weekly/template.md`'s structure: Wins, What
   Didn't Get Done, Important Lessons, Current Bottlenecks, Top Priorities
   Next Week, Tasks to Eliminate, Tasks to Delegate/Automate, Ideas to Park,
   Strategic Recommendation.
4. Be honest, not encouraging-for-its-own-sake — if little got done, say so
   and say why (per `core/instructions.md`'s tone).
5. If the review surfaces a durable lesson, add it to
   `glovak-executive-assistant/memory/lessons.md`.
6. If it surfaces a workflow improvement, add it to
   `glovak-executive-assistant/logs/improvement-backlog.md` rather than
   changing anything automatically.
7. Show the review in chat and confirm the file was saved.

Low-risk organizational action — no confirmation needed to save the file.
