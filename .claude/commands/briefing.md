description: Produce today's executive briefing
---

Read `glovak-executive-assistant/core/instructions.md` first for persona and
rules, then produce a Daily Briefing.

1. Read `glovak-executive-assistant/tasks/tasks.md`,
   `glovak-executive-assistant/projects/projects.md`, and
   `glovak-executive-assistant/memory/active-goals.md`.
2. Determine today's date (ask if you can't determine it reliably).
3. Create or update `glovak-executive-assistant/daily/<YYYY-MM-DD>.md` using
   the structure in `glovak-executive-assistant/daily/template.md`:
   Top 3 Priorities, Schedule, Important Tasks, Follow-ups, Business Focus,
   Personal/Admin, Potential Distractions, Recommended Next Action.
4. Base "Top 3 Priorities" on P1/P2 tasks and active project next-actions —
   don't just list everything open. Be selective; that's the point of a
   briefing.
5. If there's no calendar integration yet, say so plainly under Schedule
   instead of inventing one.
6. Show the briefing to Glovak in the chat, and mention the file was saved.

This is a low-risk organizational action — no confirmation needed before
saving the file.
