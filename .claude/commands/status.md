Read `glovak-executive-assistant/core/instructions.md` first.

Produce a compact status snapshot (not a full briefing — this is a quick
check, not a planning session):

- **Open tasks by priority** — counts and any P1s by name, from
  `glovak-executive-assistant/tasks/tasks.md`.
- **Overdue** — any task past its `Due` date.
- **Active projects** — one line each: name + current status, from
  `glovak-executive-assistant/projects/projects.md`.
- **Stalled projects** — any with no clear next action or no recent
  progress.
- **Idea Inbox** — count of items still in `INBOX`/`EVALUATING`.
- **One-line recommendation** — what deserves attention next.
